# 개발 기록

## 2026-11-08 · V0.1 시작

- Unity `6000.3.15f1` URP 샘플 프로젝트 구조를 확인했다.
- 기존 장면은 Main Camera, Directional Light, Global Volume, Player, Ground와 기본 이동 스크립트로 구성되어 있었다.
- 기존 `BootTest`가 같은 GameObject에 여러 번 붙어 있어 정적 설치 가드로 중복 생성을 막았다.
- 클릭형 웹 프로토타입과 분리해 Unity 런타임에서 임시 3D 발가락, 발톱, 핀셋, 트레이를 생성하는 `ToeProcedureV01`을 추가했다.
- 핀셋 드래그, 두 손가락 회전·확대, 핀셋 개폐, 접촉 거리 기반 파지, 트레이 해제, 절차형 효과음을 구현했다.
- 실사 매크로 이미지는 시각 참고용 임시 에셋으로 연결했다. 최종 제품에는 라이선스가 확인된 3D 모델과 PBR 텍스처가 필요하다.

### 테스트

- 코드 파일과 프로젝트 설정은 로컬 Git 커밋 `7fdda33`으로 저장했다.
- Unity Hub에 유효한 Editor 라이선스가 없어 에디터 실행과 실제 모바일 입력 테스트는 BLOCKED 상태다.
- 라이선스 활성화 후 Unity에서 컴파일 오류, 핀셋 접촉, 파지, 트레이 해제를 우선 검증한다.

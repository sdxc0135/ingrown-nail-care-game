# 내성발톱 리얼 시뮬레이터 로드맵

## 최종 목표

실제 의료 행위를 교육하지 않는 가상 게임으로, 플레이어가 모바일 터치로 도구를 직접 이동·회전·개폐하고 발톱 조각과 접촉시키는 리얼 클리닉 시뮬레이션을 만든다.
